## Next.js requires a planned major upgrade

Next.js 14 is outside the project's supported release lines. The current Next.js support policy lists 16.x as Active LTS and 15.x as Maintenance LTS, with security releases for 15.x through 2027-01-31.

The 14.2.35 version is not a safe long-term target. Current advisory tracking reports multiple unresolved advisories for that release line. The November 2026 security fixes identify 15.5.29 as a patched 15.x release and 16.4.5 as a patched 16.x release.

References:
- https://nextjs.org/support-policy
- https://nextjs.org/blog
- https://npmscan.io/package/npm/next%4014.2
- https://npmscan.io/package/npm/next%4015.5

## Safe upgrade sequence

Do not change only `package.json`: the lockfile must be regenerated by npm and validated with `npm ci`.

1. Create an isolated dependency-upgrade branch from `promptforge-v2-development`.
2. Evaluate Next.js 15.5.29 with the project's current App Router code and React 18 dependencies. Confirm the supported React peer dependency range from the exact release metadata before choosing React versions.
3. If the chosen Next.js release requires React 19 for this App Router setup, migrate React and React DOM together and update the corresponding type packages.
4. Regenerate `package-lock.json` with npm; do not hand-edit lockfile versions.
5. Run `npm ci`, all Vitest tests, TypeScript, and the production build.
6. Review Next.js migration warnings and test authentication, streaming AI responses, file uploads, route handlers, and Supabase session behavior.
7. Only after all checks pass, propose the upgrade for review. Do not deploy automatically.
